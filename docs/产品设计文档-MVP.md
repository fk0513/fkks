| 项 | 内容 |
|---|---|
| 产品代号 | `fkks-reader`（待定） |
| 文档版本 | v1.0 |

---

## 1. 产品定位

### 1.1 一句话定义

一个**打开即用、无需安装、不依赖账号**的网页版电子书阅读器，让用户把本地电子书拖进浏览器就能舒服地读完，并在阅读过程中随手做标注。

### 1.2 目标用户

- 有本地电子书文件（EPUB / TXT），但不想装专用阅读软件的用户
- 需要在电脑和手机之间切换阅读、又不愿意折腾同步服务的用户
- 有做读书笔记习惯、但现有工具（阅读器 + 笔记 App 分离）体验割裂的用户

### 1.3 MVP 要验证的核心假设

> **用户愿不愿意用它读完一整本书，并且愿意在里面做标注。**

产品成功与否，不看功能数量，只看两件事：

1. 用户能顺畅地从第一章读到最后一章，进度不丢；
2. 用户愿意在阅读过程中划重点、写笔记，并且会回来看。

### 1.4 明确不做（Out of Scope）

以下内容**在 MVP 阶段坚决不做**，出现即视为范围蔓延：

| 不做的事 | 原因 |
|---|---|
| PDF / MOBI / AZW3 格式支持 | PDF 固定版式重排是独立课题；MOBI 格式封闭。会让 MVP 变成两个产品 |
| 账号体系、云同步 | 引入后端即引入系统复杂度，且带出隐私合规问题。MVP 用本地存储解决 |
| 在线书城、书源下载 | 版权雷区，MVP 不碰 |
| 书架分组、标签管理 | 属于"书多了以后"的需求，MVP 阶段验证不到 |
| 全文搜索 | 实现成本高、收益验证滞后 |
| 标注导出（Markdown / Notion / 图片） | 是 v1.1 的留存钩子，不是 MVP 的必要条件 |
| TTS 朗读、翻译、AI 问答 | 典型功能膨胀陷阱，会稀释对核心体验的判断 |
| 社交分享、评论 | 与核心假设无关 |

## 2. 功能范围（MVP）

### 2.1 功能清单

| # | 模块 | 功能点 | 优先级 | 说明 |
|---|---|---|---|---|
| F1 | 导入 | 拖拽 / 文件选择导入 EPUB | P0 | 支持 `.epub` |
| F2 | 导入 | 导入 TXT，自动识别编码、自动分章 | P0 | 支持 UTF-8 / GBK；按"第X章 / Chapter N"等规则切章 |
| F3 | 书架 | 书籍列表 + 封面 + 书名/作者 | P0 | 按最近阅读时间排序，不做分组 |
| F4 | 阅读器 | EPUB 内容渲染（分页 / 滚动两种模式） | P0 | 产品心脏 |
| F5 | 阅读器 | 上一页 / 下一页 / 键盘方向键翻页 | P0 | |
| F6 | 目录 | 解析 TOC（EPUB nav / NCX），点击跳转 | P0 | 长书没目录不可用 |
| F7 | 进度 | 自动记录阅读位置，下次打开续读 | P0 | 基于 CFI / 百分比 |
| F8 | 标注 | 选中文本 → 高亮（多颜色） | P0 | 核心差异化 |
| F9 | 标注 | 为高亮添加笔记文字 | P0 | |
| F10 | 标注 | 标注侧栏：查看 / 跳转 / 删除 | P0 | |
| F11 | 设置 | 字号调节 | P1 | |
| F12 | 设置 | 行距调节 | P1 | |
| F13 | 设置 | 背景主题（浅色 / 深色 / 护眼） | P1 | |
| F14 | 设置 | 字体族切换 | P1 | |
| F15 | 书架 | 删除书籍（含其标注数据） | P1 | 数据卫生必需 |

**P0 = 缺了就不算 MVP；P1 = 有则体验明显更好，但没有也能交付。**

### 2.2 用户核心流程

```
进入首页（书架）
   │
   ├─ 空状态 → 引导拖拽导入
   │
   └─ 有书 → 点击书籍封面
                │
                ▼
           进入阅读器
                │
                ├─ 自动跳转至上次阅读位置
                ├─ 翻页 / 目录跳转
                ├─ 选中文本 → 弹出操作条 → 高亮 / 高亮+笔记
                ├─ 打开标注侧栏 → 查看 / 跳转 / 删除
                └─ 调整阅读设置 → 实时生效
                │
                ▼
           退出 → 自动保存进度与标注
```

### 2.3 明确排除在 MVP 之外的交互

- 不支持多人协作标注
- 不支持跨设备同步（换设备看不到标注）
- 不支持标注的分享 / 导出
- 不支持自定义高亮颜色

## 3. 页面与交互设计

### 3.1 页面结构

MVP 共 **3 个页面/视图**：

| 视图 | 路由 | 职责 |
|---|---|---|
| 书架 | `/` | 展示所有已导入书籍，提供导入入口 |
| 阅读器 | `/read/:bookId` | 正文渲染、翻页、目录、标注、设置 |
| 空状态 | `/`（无书时） | 引导导入，降低首次使用门槛 |

### 3.2 书架页

**布局**

```
┌─────────────────────────────────────────────┐
│  📚 我的书架                    [+ 导入书籍] │
├─────────────────────────────────────────────┤
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐    │
│  │ 封面 │  │ 封面 │  │ 封面 │  │ 封面 │    │
│  │      │  │      │  │      │  │      │    │
│  └──────┘  └──────┘  └──────┘  └──────┘    │
│   书名      书名      书名      书名        │
│   作者      作者      作者      作者        │
│   ▓▓▓░░ 42%  已读完                        │
└─────────────────────────────────────────────┘
```

**要点**

- 封面缺失时用「书名首字 + 渐变色块」生成占位封面
- 书籍卡片显示阅读进度条
- 悬停显示删除按钮（二次确认）
- 支持整页拖拽导入，拖入时显示高亮遮罩

### 3.3 阅读器页

**布局（分页模式）**

```
┌─────────────────────────────────────────────┐
│ ← 返回   书名 · 第 3 章            ☰ 目录  Aa │  ← 顶栏（滚动时自动隐藏）
├─────────────────────────────────────────────┤
│                                             │
│   正文内容……                                │
│                                             │
│   ……一段被高亮的文字（黄色背景）            │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│  42%  ←────────●──────────────→  第 87/210 页│  ← 底栏
└─────────────────────────────────────────────┘
```

**选中文本后的操作条**

```
        ┌─────────────────────────┐
        │  🟡  🟢  🔵  📝  ✕       │
        └─────────────────────────┘
              ↑ 浮于选中文本上方
```

- 前三项：直接打高亮（黄 / 绿 / 蓝）
- `📝`：打高亮并立刻打开笔记输入框
- 点击已有高亮：显示「编辑笔记 / 删除」

### 3.4 交互细节约定

| 场景 | 行为 |
|---|---|
| 键盘 ← → | 上一页 / 下一页 |
| 键盘 Esc | 关闭当前浮层（目录 / 侧栏 / 设置） |
| 点击正文左右 1/3 区域 | 翻页（可配置是否开启） |
| 移动端左右滑动 | 翻页 |
| 滚动模式 | 顶栏/底栏随滚动方向自动隐藏/显示 |
| 切换设置后 | 保持当前阅读位置不跳动（关键体验点） |

## 4. 数据模型

全部数据存储在浏览器 **IndexedDB**，不涉及服务端。

### 4.1 表设计

**`books`** —— 书籍

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string (PK) | UUID |
| `title` | string | 书名 |
| `author` | string | 作者，可空 |
| `format` | string | `epub` \| `txt` |
| `cover` | Blob | 封面图，可空 |
| `file` | Blob | 原始文件内容 |
| `fileSize` | number | 字节数 |
| `chapterCount` | number | 章节数 |
| `importedAt` | number | 导入时间戳 |
| `lastReadAt` | number | 最后阅读时间戳（用于排序） |

**`progress`** —— 阅读进度

| 字段 | 类型 | 说明 |
|---|---|---|
| `bookId` | string (PK) | 外键 → books.id |
| `location` | string | EPUB 用 CFI；TXT 用 `章节索引:段落索引` |
| `percentage` | number | 0–100 |
| `chapterIndex` | number | 当前章节序号 |
| `updatedAt` | number | 更新时间戳 |

**`annotations`** —— 标注

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string (PK) | UUID |
| `bookId` | string (IDX) | 外键 → books.id |
| `type` | string | `highlight` \| `note` |
| `color` | string | `yellow` \| `green` \| `blue` |
| `range` | string | EPUB CFI 范围；TXT 用 `章节:起-止` |
| `text` | string | 被选中的原文（用于侧栏展示） |
| `note` | string | 用户笔记内容，可空 |
| `chapterIndex` | number | 所属章节 |
| `createdAt` | number | 创建时间戳 |

**`settings`** —— 阅读偏好（**按书籍存**，一本书一套）

| 字段 | 类型 | 说明 |
|---|---|---|
| `bookId` | string (PK) | 外键 → books.id |
| `fontSize` | number | 字号 px |
| `lineHeight` | number | 行距倍数 |
| `theme` | string | `light` \| `dark` \| `sepia` |
| `fontFamily` | string | 字体族 |
| `flow` | string | `paginated` \| `scrolled` |

### 4.2 索引

- `books.lastReadAt` —— 书架排序
- `annotations.bookId` —— 按书查标注
- `annotations.[bookId+chapterIndex]` —— 按章节渲染标注（复合索引）

### 4.3 数据生命周期

- 删除书籍 → 级联删除其 `progress`、`annotations`、`settings`
- 存储占用：EPUB 原文件存 Blob，受浏览器配额限制；需在导入时校验剩余空间
- 不提供数据导出（MVP 范围外），但删除前必须二次确认

## 5. 技术方案

### 5.1 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | **Svelte 5 + Vite** | 体积小、无虚拟 DOM，适合阅读器这种以渲染为主的应用；也可换 React |
| 路由 | SvelteKit 或 `svelte-spa-router` | 仅需两个路由，用轻量的即可 |
| EPUB 解析 | **foliate-js** | 现代方案，对 CFI、标注、TOC 支持好，原生支持分页 |
| TXT 解析 | 自研（约 200 行） | 编码识别用 `jschardet`，分章用正则 |
| 存储 | **Dexie.js**（IndexedDB 封装） | API 友好，事务和索引支持完善 |
| 样式 | 原生 CSS + CSS 变量 | 主题切换靠变量，无需引入 UI 框架 |
| 部署 | Vercel / Netlify / GitHub Pages | 纯静态，零服务器成本 |

> **备选**：若团队更熟悉 React，可换 `epub.js` + `epubjs-react`，但其维护活跃度不及 foliate-js，且标注 API 偏底层。

### 5.2 关键技术风险

| 风险 | 说明 | 应对 |
|---|---|---|
| **移动端文本选中** | 移动浏览器（iOS Safari / Android Chrome）的选区 API 行为差异大，选中后弹操作条易被系统菜单遮挡 | **第一周就做 demo 验证**，不要拖到最后 |
| **切换设置时的位置跳动** | 改字号/行距后内容重排，容易"跳页" | 以 CFI 为锚点重设位置，切换前记录、渲染后还原 |
| **IndexedDB 容量** | 大 EPUB 文件可能触达浏览器配额 | 导入时校验，超限给出明确提示 |
| **TXT 分章质量** | 章节标题格式千奇百怪 | 正则规则可配置，识别失败时降级为「按固定字数分章」 |
| **EPUB 兼容性** | 部分 EPUB 的 CSS 会破坏阅读样式 | 注入基础样式表强制覆盖，提供「原版排版」开关（P1） |

### 5.3 目录结构（建议）

```
fkks-reader/
├── src/
│   ├── routes/
│   │   ├── +page.svelte          # 书架
│   │   └── read/[bookId]/+page.svelte
│   ├── lib/
│   │   ├── db/                   # Dexie schema 与操作
│   │   ├── parsers/              # epub / txt 解析
│   │   ├── annotation/           # 标注渲染与命中
│   │   └── stores/               # 全局状态
│   ├── components/
│   │   ├── BookCard.svelte
│   │   ├── ReaderView.svelte
│   │   ├── TocSidebar.svelte
│   │   ├── AnnotationPanel.svelte
│   │   ├── SettingsPanel.svelte
│   │   └── SelectionToolbar.svelte
│   └── styles/
├── static/
└── package.json
```

## 6. 里程碑拆解

| 阶段 | 交付内容 | 验收标准 |
|---|---|---|
| **M1 · 骨架** | 项目初始化、路由、Dexie schema、书架空状态 | 能跑起来，能看到书架页 |
| **M2 · 导入与书架** | EPUB/TXT 导入、封面提取、书籍列表、删除 | 导入 3 本不同的书都能正常显示 |
| **M3 · 阅读核心** | EPUB 渲染、翻页、目录、TXT 渲染 | 完整读完一本 EPUB 的中篇 |
| **M4 · 进度与设置** | 进度记录/续读、字号行距主题字体 | 关掉浏览器重开，位置一致；改设置不跳页 |
| **M5 · 标注体系** | 高亮、笔记、侧栏、删除 | 标注后重开仍在原位，侧栏能跳转 |
| **M6 · 打磨** | 移动端适配、性能优化、边界处理 | 手机浏览器上能顺畅读 + 选中标注 |

**M6 不是"有空再做"，移动端选中交互必须专门验证。**

## 7. 验收标准

MVP 交付前，以下场景必须全部通过：

### 7.1 功能验收

- [ ] 导入 EPUB：能正确解析书名、作者、封面、目录
- [ ] 导入 TXT：能正确识别编码（UTF-8 / GBK）并自动分章
- [ ] 导入失败（损坏文件 / 不支持格式）时有明确错误提示
- [ ] 书架正确显示所有书籍，按最近阅读排序
- [ ] 点击书籍进入阅读器，**自动定位到上次位置**
- [ ] 分页模式下翻页流畅，无内容截断
- [ ] 目录可展开、可跳转，跳转后位置正确
- [ ] 选中文本能弹出操作条，打高亮成功
- [ ] 高亮后能添加笔记，笔记内容可编辑
- [ ] 标注侧栏列出所有标注，点击可跳转原文
- [ ] 删除标注后，正文中高亮同步消失
- [ ] 删除书籍后，其进度、标注、设置一并清除

### 7.2 体验验收

- [ ] 修改字号 / 行距后**阅读位置不跳动**
- [ ] 主题切换即时生效，文字对比度符合可读性（WCAG AA）
- [ ] 关闭浏览器重新打开，**进度和标注完整保留**
- [ ] 移动浏览器（iOS Safari + Android Chrome）能正常翻页
- [ ] 移动端选中文本时，操作条不被系统菜单遮挡
- [ ] 键盘操作（← → / Esc）正常

### 7.3 性能验收

- [ ] 10MB 以内的 EPUB 导入耗时 < 3s
- [ ] 翻页响应 < 100ms（无感知延迟）
- [ ] 书架加载 50 本书 < 1s
- [ ] 内存占用稳定，连续翻 500 页不出现明显泄漏

### 7.4 兼容性验收

- [ ] Chrome / Edge 最新版
- [ ] Safari 最新版（含 iOS）
- [ ] Firefox 最新版

## 附录：术语表

| 术语 | 含义 |
|---|---|
| CFI | EPUB Canonical Fragment Identifier，EPUB 中用于精确定位内容位置的标识符 |
| TOC | Table of Contents，目录 |
| NCX | EPUB 2 的目录格式；EPUB 3 使用 nav 文档 |
| IndexedDB | 浏览器内置的结构化数据库，支持存储 Blob 大文件 |
| 分页模式 | 内容按屏幕高度切成页，左右翻页 |
| 滚动模式 | 内容连续滚动，上下滑动 |
